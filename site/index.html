Your passwords, in one encrypted file on your computer.

kv-vault is a free, open-source password manager. No account, no server of ours, no telemetry — the vault never leaves your machine unless you put it in your own cloud folder.

Download All downloads

Windows 10/11 and Linux (AppImage, .deb). Free, MIT licensed.

Everything a password manager does — on your terms

Fills sign-ins in your browser

An extension for Chrome, Edge and Firefox fills the login for the site you're on and offers to save new ones. It talks to this computer only — no port, no account — and only once you turn it on.

Imports what you already have

Chrome, Edge, Firefox and Safari exports, 1Password, Bitwarden, KeePass and LastPass. Duplicates are skipped, and the app offers to delete the plaintext export afterwards.

Password health

Reused, weak and year-old passwords, and logins without two-factor, in one view. An opt-in breach check sends only 5 characters of each password's hash.

Two-factor codes

Paste a site's two-factor key into a login and the current 6-digit code is one click away.

Sync without a server

Pick a folder your cloud already syncs — Drive, Dropbox, OneDrive, iCloud. An encrypted copy lives there and changes merge item by item.

Share with one person

Seal an item to someone's sharing key into a .kvshare file. Only their vault can open it.

A way back

An emergency export under a recovery code you print. Forget the master password, and the code still opens your vault.

Cards, notes, Wi-Fi, servers

Typed items for what you keep besides logins — and in English or Hebrew, dark or light.

How it keeps your secrets

  • Well-known cryptography, nothing home-made. Argon2id turns your master password into a key; XChaCha20-Poly1305 encrypts the whole vault — names included. Both come from libsodium.
  • One file you own. ~/.keyvault/vault.kv. Copy it, back it up, sync it — it is useless without the password.
  • Locks itself after 15 idle minutes and whenever Windows locks. Copied passwords stay out of clipboard history and cloud clipboard.
  • Updates you can check. The app installs only updates signed with the project's key. Every download has a build attestation from this repository's release workflow, a checksum and an SBOM.
  • Open source. Every line is on GitHub, tested on Windows, macOS and Linux on every change. Found a problem? Report it privately.

For developers: keys without .env files

The same vault has a kv command line (Node.js 22.6+, Windows, macOS, Linux). Run a project with its keys as environment variables, push them to Vercel or GitHub, and stop a commit that contains any of them.

npm install -g https://github.com/liormedan/kv-vault/releases/latest/download/kv-vault.tgz
kv set my-app/OPENAI_API_KEY      # typed hidden, never on the command line
kv run my-app -- npm run dev      # the app gets its keys; no .env on disk
kv guard install                  # a pre-commit hook that blocks leaked values

Good to know

  • The Windows installer is not code-signed yet, so Windows may say the publisher is unknown: More info → Run anyway. You can check where a file came from: gh attestation verify <file> --repo liormedan/kv-vault.
  • A macOS app is not available yet; the command line works on macOS.
  • The browser extension is installed from the app for now (it is not in the Chrome Web Store or Firefox Add-ons yet).
